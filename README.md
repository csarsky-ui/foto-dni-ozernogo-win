# Фото на документы — «Дни Озёрного» (версия для Windows 10 / 11, 64-bit)

Полностью автономная (офлайн) программа для редакции газеты **«Дни Озёрного»**: загружает RAW (`.CR2`, `.CR3`, `.NEF`, `.ARW`, `.DNG` и др.) и обычные фото (`.JPG`, `.PNG`, `.TIFF`), автоматически выравнивает голову по глазам, чисто вырезает фон на белый (`#FFFFFF`), выполняет студийную ретушь дизайнера, раскладывает на вертикальный лист **10×15 см (`300 DPI`, `sRGB`)** с логотипом **«Дни Озёрного»** внизу, сохраняет **многослойный `.PSD` с редактируемыми масками и направляющими**, **JPEG на печать** и отправляет в печать **1:1 на `EPSON L8050 Series`**.

---

## Возможности (1-в-1 как в версии для macOS)

- **Все 9 форматов на вертикальном листе 10×15 см (`100×150 мм`, `1181×1772 px`, `300 DPI`):**
  - `3×4 см` — 6 шт (`2×3`)
  - `3,5×4,5 см — Паспорт РФ` — 4 шт (`2×2`: от макушки до верха **5,0 мм**, голова **30–32 мм / цель 31 мм**, глаза по центру с линейкой расстояния до краёв)
  - `3,5×4,5 см — Виза / Загран` — 4 шт (`2×2`)
  - `2,5×3,5 см — Удостоверение ветерана` — 6 шт (`2×3`) и 9 шт (`3×3`)
  - `4×5 см` (4 шт), `4×6 см` Военкомат/МВД (4 шт), `9×12 см` (1 шт), `Комби: 3×4 (4 шт) + 3,5×4,5 (2 шт)`
- **Уголки и ЧБ:** цветное / портретное ЧБ; 5 вариантов уголка (`без уголка`, `справа/слева овал`, `справа/слева прямой`); автоматический выбор зелёного или серого логотипа «Дни Озёрного» внизу листа.
- **Студийная ретушь (офлайн):** анти-блеск от вспышки на носу и лбу, точечное удаление красных глаз (с честным индикатором «обнаружены / не обнаружены»), выравнивание скинтона, деликатная микро-ретушь кожи (глаза, ресницы, брови и губы не замыливаются), авто-баланс белого по фону и печатная светлота.
- **Настоящий многослойный `.PSD`:** слой `#FFFFFF`, отдельные слои для каждого фото с **редактируемыми слой-масками Photoshop**, отдельные слои `Уголки`, `Метки реза`, `Логотип Дни Озёрного`, встроенный профиль `sRGB IEC61966-2.1` и направляющие (Guides) по всем линиям реза.
- **Прямая печать на `EPSON L8050 Series` (масштаб 1:1):** запоминает ваш родной бинарный профиль драйвера Windows (`DEVMODE`) один раз и дальше печатает в 1 клик без повторных настроек.

## Как получить готовый `FotoDniOzernogo.exe` через GitHub Actions (без установки Python)

1. Создайте на [github.com](https://github.com/new) новый **приватный (Private)** репозиторий (например, `foto-dni-ozernogo-win`) — галочки *Add a README / .gitignore* **не ставьте**.
2. В Терминале на Mac внутри этой папки выполните две команды (подставьте свой URL репозитория):
   ```bash
   git remote add origin https://github.com/<ваш-логин>/foto-dni-ozernogo-win.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** на GitHub → откроется сборка **«Build Windows EXE (Foto na dokumenty)»** (занимает ~4–6 минут).
   - GitHub автоматически скачает Windows Python 3.11, офлайн-модели AI (`RMBG-1.4` и `MediaPipe`), проверит готовый `.exe` тестовым прогоном и соберёт единый архив.
4. Когда рядом со сборкой появится зелёная галочка ✅, пролистайте вниз до блока **Artifacts** и скачайте **`FotoDniOzernogo-Windows-x64.zip`**.

*(Альтернатива без GitHub: на любом Windows-ПК с установленным Python 3.11 можно просто дважды кликнуть `build_windows.bat`.)*

## Установка и работа на рабочем ПК с Windows 10 / 11

1. Распакуйте `FotoDniOzernogo-Windows-x64.zip` в любую удобную папку (например, `C:\FotoDniOzernogo` или на Рабочий стол — кириллица в путях полностью поддерживается).
2. Запустите **`FotoDniOzernogo.exe`** (при первом запуске Windows SmartScreen может показать «Защита компьютера» → нажмите **«Подробнее» → «Выполнить в любом случае»**, так как приложение не подписано платным сертификатом Microsoft).
   - Интернет для работы **не нужен** — все AI-модели уже вшиты внутрь папки.
3. **Однократная настройка профиля печати `EPSON L8050 Series`:**
   - В правой панели внизу нажмите **«Настроить и запомнить профиль Epson L8050…»**.
   - В открывшемся стандартном окне драйвера Epson выберите ваш готовый набор настроек (или задайте: `10×15 см (4×6 дюймов)`, `Epson Matte`, `Качество: Высокий`, `Без полей: Выкл`, `Цветокоррекция: Пользовательский → EPSON Насыщенный, Гамма 2.2`, `Обратный порядок: Вкл`, `Повернуть на 180°: Вкл`, `Быстрая печать / двунаправленная: Выкл`, `Устранение эффекта красных глаз: Выкл`) и нажмите **ОК**.
   - Программа сохранит профиль в `%APPDATA%\FotoDniOzernogo\epson_l8050_profile.devmode`.
4. Дальше для каждого клиента: перетащите `.CR2`/`.JPG` в окно → выберите формат (например, `3×4 (6 шт)` или `Паспорт РФ`) → проверьте кадрирование и линейку → **«Сохранить PSD…»** или **«Печать»** в 1 клик.
